인덱스란?

데이터를 빠르게 찾기 위한 도구. 오라클에서 자동 생성 또는 개발자가 직접 생성한다. 단, 인덱스 또한 생성의 개념이므로 디스크 공간을 차지한다.

의미 없는 인덱스를 많이 만들면 오히려 안 쓰는게 더 빠르다.

이점

  • where 조건 검색 시 속도가 빠름
  • 정렬 속도 향상 (order 절)
  • 중복 제거 속도 향상 (DISTINCT, GROUP 절)

단점

insert, update, delete 의 경우 오히려 더 느려진다.

사용 예시

CREATE INDEX idx_emp_name ON emp (ename);

SELECT * FROM emp WHERE ename = 'SMITH';
상황인덱스
조회 중심 테이블권장
쓰기 빈번한 테이블신중

유의 사항

UPPER 쓰면 인덱스가 동작 안 해요. LIKE 절의 앞에 % 가 붙으면 인덱스를 타지 않아요.
