# ADR 0002: 공식 문서는 벡터화하지 않고 큐레이션 링크로

- 상태: 채택 (2026-10-16)

## 배경

"관련 문서" 버튼은 글과 관련된 공식 문서 링크를 보여주면 된다. 공식 문서(React, Oracle, MDN …)를 통째로 수집·임베딩하면
청크가 수만 개가 되어 Vectorize 무료 저장 한도(≈ 4,800개)를 넘고, 크롤링 정책(robots, 라이선스)도 신경 써야 한다.

## 결정

- 블로그 카테고리 기준으로 공식 문서 링크를 손으로 고른다 (`worker/seed/doc_links.sql`, 현재 41개)
- 각 링크에 키워드를 달고, 글의 태그/카테고리/제목과 IDF 가중 매칭해 상위 3개를 보여준다 ([rag-design.md](../rag-design.md#관련-공식-문서-매칭-docsjs))
- 링크는 seed에 있는 것만 나간다. LLM이 링크를 만들지 않는다

## 결과

- 비용 0, 지어낸 링크 없음, 모든 URL은 작성 시 HTTP 200 확인
- 블로그에 없는 주제(Python 등)는 문서가 안 나온다. 주제가 늘면 seed에 추가
- 문서 내용 안까지 검색하지는 않는다
