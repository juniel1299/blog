# ADR 0005: 하이브리드 검색 + 실데이터로 맞춘 임계값

- 상태: 채택 (2026-10-16)

## 배경

블로그 글은 한국어와 영어 기술 용어가 섞여 있다. 의미 검색만 쓰면 무관한 질문에도 무언가를 돌려주고,
키워드만 쓰면 표현이 다른 질문을 놓친다.

## 결정

- 키워드(FTS5 trigram + 2자 단어 LIKE) + 의미(bge-m3/Vectorize)를 RRF로 합친다
- 관련도 관문: 의미 점수 ≥ 0.5, 제목/소제목 키워드 일치는 항상 인정, 본문만의 키워드 일치는 의미 점수도 0.5 이상일 때만
- 흔한 제목 단어(차이, 정리 …)는 불용어, 한국어 음역(뷰, 리액트 …)은 영어 단어를 함께 검색
- 모든 임계값은 `/admin/search-debug`, `/admin/similar-debug`로 실제 점수를 보고 정하고, 평가 세트로 회귀를 막는다

## 근거 (2026-10-16)

- 관련 질문 의미 점수 0.55~0.77, 무관한 질문 ≤ 0.48 → 0.5
- 본문 키워드 관문 0.4에서 "오늘 날씨" → Calendar 글 오탐 → 0.5로 올림
- 평가: hit@3 97% → (음역 별칭) 100%, top1 90% → 93%, 오탐 0%

## 결과

- 블로그에 없는 주제에는 "찾지 못했어요"를 정직하게 보여준다
- 글이 늘면 점수 분포가 바뀔 수 있다 → 평가 세트를 늘리고 다시 측정
