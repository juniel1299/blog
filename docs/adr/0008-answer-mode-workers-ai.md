# ADR 0008: Q&A 답변 모드는 Workers AI Gemma 4 (생각 끔)

- 상태: 채택 (2026-10-20)

## 배경

"useEffect는 언제 실행돼?" 같은 질문에는 카드 목록보다 블로그 글을 근거로 한 짧은 답이 낫다. 조건은 무료(Cloudflare 무료 플랜 안에서),
블로그 글에 없는 내용은 지어내지 않기, 근거 글을 바로 열 수 있게 하기.

## 후보 비교 (2026-10-20, 실제 글 3개 + 블로그에 없는 질문 1개, 같은 프롬프트)

| 모델 | 결과 | 1회 비용 | 응답 |
|---|---|---|---|
| `@cf/google/gemma-4-26b-a4b-it` (생각 끔) | 4개 모두 정확, 출처 번호 정확, 없는 주제는 "찾지 못했어요" | ≈ 15 neurons | 2~3초 |
| `@cf/zai-org/glm-4.7-flash` (생각 끔) | 내용은 맞지만 오타("inset")와 덧붙임 | ≈ 15 neurons | 1~7초 |
| `@cf/qwen/qwen3-30b-a3b-fp8` | 생각 켜면 정확·빠름, 끄면 답이 `reasoning` 필드로 나옴 | ≈ 10~19 neurons | 1~4초 |
| Gemma 4 / GLM (생각 켬) | 400토큰을 모두 생각에 써서 답이 비어 옴 | - | - |
| Claude Haiku 5.5 (Anthropic API) | 품질은 더 높을 것으로 예상 ($0.10/$0.50 per MTok, 1회 ≈ $0.0004) | 유료 + API 키 필요 | - |

## 결정

- `@cf/google/gemma-4-26b-a4b-it`, `chat_template_kwargs: { enable_thinking: false }`, `max_tokens` 500
- 근거: 하이브리드 검색 상위 3개 글, 글마다 일치한 소제목부터 1,500자
- 출처에 답이 없으면 정해진 문장("블로그 글에서 답을 찾지 못했어요.") → 답 대신 카드
- 없는 출처 번호(`[5]` 등)는 지운다. 링크는 출처 카드의 글 URL뿐 (LLM이 URL을 만들지 않음)
- 실패(무료 한도 소진 포함) → 503, 위젯은 일반 검색으로 대체

## 결과

- 비용 0: 무료 10,000 neurons/일 ≈ 답변 600개 (검색 임베딩 몫 제외)
- 질문형 입력만 답변 모드(위젯 `isQuestion`), "…글 찾아줘"는 지금처럼 카드
- 품질이 부족하면 Claude Haiku 5.5로 바꿀 수 있다 (유료, `ANTHROPIC_API_KEY` 시크릿 필요)
