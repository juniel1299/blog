# ADR 0006: 스킨은 기존 스킨을 보관한 뒤 편집 화면에서 교체

- 상태: 채택 (2026-10-16)

## 배경

기존 스킨("한눈에 스킨", 사용자 수정)에는 애드센스, 네이버 사이트 인증, 스킨 옵션 기반 광고 슬롯이 들어 있었다.
새 스킨을 zip으로 "스킨 등록"할 수도, 현재 스킨의 HTML/CSS를 편집 화면에서 바꿀 수도 있다.

## 결정

- 먼저 현재 스킨을 **스킨 보관함에 백업**("한눈에 스킨 백업 2026-10-16")
- 편집 화면에서 HTML/CSS를 새 스킨으로 바꾸고 `images/script.js`를 업로드
- 애드센스 로더와 네이버 인증 메타는 새 `<head>`로 옮김
- 이후 변경은 "직전에 반영한 내용과 같은지" 확인 후 바뀐 부분만 교체

## 결과

- 언제든 보관함 백업으로 되돌릴 수 있다
- `index.xml`(스킨 옵션)은 기존 것이 남아 있다. 새 스킨은 옵션을 쓰지 않아 영향 없음
- 기존 스킨의 수동 광고 슬롯은 없어졌다 (자동 광고만 가능) → 2026-10-22 `skin.html`에 직접 넣어 복구 ([skin.md](../skin.md))
- 티스토리 업로드 API가 없어 스킨 반영은 계속 수동 ([0007](0007-ci-auto-deploy.md))
