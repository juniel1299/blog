# ADR 0004: 한 줄 미리보기는 추출식 (LLM 요약 보류)

- 상태: 채택 (Phase 3, 2026-10-16)

## 배경

결과 카드의 한 줄 미리보기를 (a) 검색된 청크에서 문장을 골라 보여주거나, (b) Workers AI LLM(llama-3.1-8b)으로 요약할 수 있다.
(b)는 더 자연스럽지만 응답이 1~2초 늘고, 검색당 약 50 neurons(무료로 하루 약 200회)를 쓰며, 요약이 원문과 다를 위험이 있다.

## 결정

추출식을 유지한다. 질문 단어가 들어 있는 한국어 문장을 우선하고 코드 줄은 피한다 (`makeSnippet`).

## 결과

- 비용 0, 지연 없음, 내용을 지어낼 수 없음
- 문장이 가끔 어색할 수 있다. 필요해지면 LLM 요약을 다시 검토 (캐시 + 한도 초과 시 추출식으로 대체하는 형태)
- Reranker도 같은 이유로 보류. 평가 지표(hit@3 100%, top1 93%)상 지금은 필요 없음
